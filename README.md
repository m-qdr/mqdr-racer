# MQDR Racer 🚁

Система судейства гонок дронов: пилоты, заезды с живым хронометражем кругов, автоматический подсчёт очков и турнирная таблица.

Всё приложение — **один файл `index.html`** без зависимостей и сборки. Работает офлайн, данные хранятся в браузере (localStorage).

---

## Запуск

Вариант 1 — просто открыть файл:

```
откройте index.html двойным кликом в любом современном браузере
```

Вариант 2 — через локальный сервер (если нужен доступ с других устройств в сети):

```bash
# Python
python -m http.server 8080

# или Node.js
npx serve .
```

Затем откройте `http://localhost:8080`.

> Для быстрого знакомства: вкладка **«Настройки» → «Демо-данные»** загрузит 6 пилотов и два завершённых заезда с готовой турнирной таблицей.

## Возможности

### 👥 Пилоты
- Добавление пилота: имя, позывной, канал 5.8 ГГц.
- Автоматический цвет для визуального различия в таблицах.
- Статистика по пилоту: заезды, очки, лучший круг.
- Удаление каскадом (вместе с результатами в заездах).

### 🏁 Заезды
- Создание заезда и выбор участников чекбоксами.
- Старт с большим живым таймером.
- Фиксация кругов кнопкой **КРУГ** — живой счётчик текущего круга, последний и лучший круг в строке пилота.
- Кнопка **ФИНИШ** — фиксирует порядок финиша (место присваивается автоматически).
- Кнопка **−** — отмена ошибочно записанного круга.
- Защита от двойного нажатия: круг короче 0.7 с не записывается.
- Завершение заезда: не финишировавшие (DNF) получают места после финишировавших — по числу пройденных кругов.

### 🧮 Подсчёт очков
Очки пилота за заезд складываются из трёх частей:

```
очки за заезд = очки за место + бонус за быстрейший круг + очки за круги
```

| Компонент | По умолчанию | Настраивается |
|---|---|---|
| Очки за место | 100, 80, 65, 55, 50, 47, 44, 41, 38, 36, 34, 32, 30, 28, 26, 24 (далее −2 за место) | да, произвольная шкала |
| Бонус за быстрейший круг заезда | +10 | да |
| Очки за каждый пройденный круг | 0 | да |

- Быстрейший круг заезда подсвечивается зелёным, его автор получает бонус.
- Пилоты со статусом **DNS** (не стартовал) получают 0 очков.
- Изменение настроек пересчитывает очки **всех** заездов, включая уже завершённые.

### 🏆 Турнирная таблица
- Суммарные очки по всем завершённым заездам.
- Победы, число заездов, лучший круг за сезон.
- Очки по каждому заезду отдельными колонками.
- Медали за топ-3, сортировка: очки → победы → лучшее место.

### ⚙️ Данные
- Автосохранение в localStorage после каждого действия.
- **Экспорт JSON** — скачивание файла-бэкапа с меткой даты.
- **Импорт JSON** — восстановление из файла (с подтверждением).
- **Полный сброс** данных.

## Горячие клавиши (во время заезда)

| Клавиша | Действие |
|---|---|
| `1`–`9` | записать круг пилоту из строки с этим номером |
| `−` (на кнопке в строке) | отменить последний круг пилота |

## Структура данных (экспорт JSON)

```jsonc
{
  "pilots":  [ { "id", "name", "callsign", "channel", "color" } ],
  "races":   [ {
    "id", "name", "createdAt",
    "status": "ready | running | finished",
    "startedAt", "finishCounter",
    "entries": [ { "pilotId", "laps": [мс], "finishedAt", "finishOrder" } ]
  } ],
  "settings": { "placePoints": [100, 80, ...], "fastestLapBonus": 10, "lapPoints": 0 }
}
```

Времена кругов хранятся в миллисекундах; место и очки вычисляются на лету при отображении.

- Чистые HTML/CSS/JS, без фреймворков, сборки и сетевых запросов.
- Один файл `index.html` (~45 КБ), удобен для переноса на USB-накопителе судейского ноутбука.
- Адаптивная вёрстка, тёмная тема в стиле FPV-соревнований.
- Ключ хранилища: `mqdr-racer-v1`.
